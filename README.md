This application allows you to schedule customer appointments by logging in as an admin and schedule appointments for a customer. All appointments are viewable in a table and you're able to modify them. Use's MySQL to store appointment data.
In order to run the application, you must download MySQL Workbench since the application relies on it for storing customer data. Clone the repo and run the application in src/main/java/com/example/software2
/AppointmentApplication.java.
